# REPAN · Presentación web

Página pública y estática para conocer REPAN escaneando un código QR desde el teléfono.
No requiere instalar la app, crear cuenta ni descargar archivos.

- `index.html`: página única (mobile first).
- `css/styles.css`, `js/main.js`: estilos y comportamiento (sin frameworks).
- `assets/video/repan-web.mp4`: copia optimizada para web del video publicitario (H.264 + AAC, 720p, faststart).
- `assets/images/`: logo oficial, capturas reales de la app y miniaturas optimizadas (WebP).
- URL pública: https://diegoarmamdomedina-design.github.io/repan-presentacion/
